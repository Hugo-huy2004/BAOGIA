## Problem

Education Hugo needs a signed-in academic community where learners publish text, share GitHub/source code, and show images or videos without adding a paid service or storing media on Hugo infrastructure.

## Constraints

- Zero new paid service, dependency, media storage, proxy, metadata crawler, or background job.
- Hugo stores only post text and external URLs. Images and YouTube remain at their source.
- Reuse Today posts, replies, likes, visibility, rate limits, moderation, and member-safe author presentation.
- Education posts stay out of the general Today feed.
- When an external preview fails, text and the ordinary link remain usable.

## Decision

Extend `TodayPost` with optional `space: "education"`. Existing posts keep no `space`; therefore no migration is required. Add a compound feed index on `space`, `parentKey`, and `createdAt`.

The Today post API accepts only the known space `education`. Feed queries filter by space. Top-level creation stores it; replies inherit the parent's space instead of trusting the client. Duplicate-post detection includes space. Existing Today callers remain unchanged and see only posts with no space.

Education adds authenticated route `/community`, a navigation item, and a thin feed screen reusing `ThreadPost` and `ThreadComposer`. It does not duplicate the social model or moderation pipeline.

## Link Preview

Preview is derived from the first HTTP(S) URL in the post on the client. Nothing fetches metadata on the server.

- GitHub repository: local card showing `owner/repository` and the original link; no GitHub API.
- YouTube: `i.ytimg.com` thumbnail; create the iframe only after the learner presses Play.
- Direct image URL: lazy-loaded from the original host with `referrerPolicy="no-referrer"`.
- Other URL: local card showing hostname and path.
- Invalid or unsupported URL: no preview; the existing safe link renderer remains.

The renderer never accepts HTML from a post, allows only `http:` and `https:`, preserves `rel="noopener noreferrer nofollow ugc"`, and caps output at one preview per post. Editing text automatically changes the derived preview; no preview data is stored.

## Scope

Expected touch points:

- `apps/server/models/TodayPost.js`: optional space and index.
- `apps/server/routes/todayRoutes.js`: validate/filter/inherit space without changing existing Today behavior.
- `apps/web/src/services/api/modules/todayFeedApi.js`: optional space parameter.
- `apps/web/src/components/member/today/ThreadPost.jsx`: deterministic preview renderer.
- `apps/web/src/components/member/today/ThreadComposer.jsx`: pass the selected space.
- `apps/web/src/education/EduCommunity.jsx`: Education feed composition.
- `apps/web/src/education/EducationApp.jsx`, `EduShell.jsx`, `eduCopy.js`, `education.css`: route, navigation, copy, minimal layout.

No new package, Cloudinary path, upload endpoint, environment variable, fixture, or deployment service.

## Failure and Safety Rules

- External image/video failure collapses to the normal link.
- Existing per-member posting and heavy-request limits remain; link posts are ordinary small JSON requests.
- Deleted posts keep current branch-deletion behavior; no orphaned media cleanup exists because Hugo owns no media.
- Moderation still evaluates text and URLs as text. Remote media content is not scanned, so reporting/removal remains the fallback for deceptive media.
- Loading a remote image reveals the viewer's IP to its host despite the referrer being removed. This is an accepted consequence of zero-proxy media.

## Verification

Run `npm run check:all`, then manually verify:

1. General Today excludes Education posts; `/community` includes only Education posts.
2. Create, edit, reply, like, delete, pagination, private visibility, and moderation still work.
3. GitHub, YouTube, direct-image, generic, malformed, and multiple-link posts render one safe preview.
4. YouTube iframe is absent before Play; broken remote media falls back to its link.
5. Vietnamese, English, and Chinese navigation/copy exist; mobile and desktop Education navigation remain usable.

## Success Criteria

- A learner can publish text plus external source/media links and interact with replies and likes.
- No upload reaches Hugo, Cloudinary, MongoDB binary storage, or a new provider.
- Preview generation causes zero backend/API requests beyond the existing post request.
- Existing Today behavior and `npm run check:all` remain clean.
